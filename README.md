Dataset

This project uses the Credit Card Fraud Detection dataset.

The dataset contains anonymized credit card transactions made by European cardholders in September 2013. It is used to train and evalute machine learning models for identifying fraudulent transactions.

Dataset source

Download the dataset from:

Kaggle - Credit Card Fraud Detection

Dataset statistics

>Total transactions: 284,807
>Fraudulent transactions: 492
>Legitimate transations:284,315
>Features: 30 input features
>Target variable: Class
>File format: CSV
>Filename: creditcard.csv

Download instructions

1. Visit the dataset source linked above.
2. Download the dataset.
3. Extract the dowloaded file.
4. Locate creditcard.csv.
5. Place the file inside the following
  directory in this project:
  
  data/creditcard.csv

  Important

  The original dataset is not included in this GitHub's repository because it exceeds GitHub's file size limit.

  Users must dowanload the dataset seperately before running the training pipeline.
